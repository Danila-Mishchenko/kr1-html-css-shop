## Раскладка, БЭМ и позиционирование

### Раскладка
- меню навигации построено на Flexbox (`display: flex`, `gap`);
- карточки товаров выстроены в сетку CSS Grid (`grid-template-columns: repeat(3, 1fr)`);
- медиазапрос `@media (max-width: 800px)` перестраивает сетку карточек в одну колонку на узких экранах.

### БЭМ
- карточка товара — БЭМ-блок `product-card`;
- элементы блока: `product-card__title`, `product-card__text`, `product-card__price`, `product-card__badge`, `product-card__button`;
- пример модификатора: `form-field--checkbox`.

### Позиционирование
- `position: relative` — у карточки товара, служит точкой отсчёта;
- `position: absolute` — у бейджа «Новинка» (правый верхний угол карточки);
- `position: fixed` — у кнопки «Наверх» (привязана к окну браузера, не смещается при прокрутке).
